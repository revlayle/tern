## How the numbers are taken

- **Cycles** run from the first instruction of the program's `main` to its final `rts`. System startup is
  not counted (for cc65 the startup code runs first, and timing starts when `main` is entered). The Tern
  number is the one in `baseline.txt`: until `main` returns, which includes the few instructions of the entry code.
- **Bytes** are the program's code and data, and for Prog8 and cc65 the library routines it uses. Left out: the BASIC
  line, entry code and the C64 startup/exit block (Prog8); the startup modules and BSS (cc65); variables in BSS (all).
- Variables start at zero in every version. Prog8 pays cycles for clearing its BSS and initialising variables at the
  start of `main`; Tern, the assembly and cc65 rely on zeroed memory and do not.
- **Prog8**: 12.0-SNAPSHOT, `%zeropage basicsafe`, `%option no_sysinit`, default optimisation.
- **cc65**: `cl65 -t none -Oirs -Cl` (inlining, register variables, static locals).
- **Assembly**: written for the task, in the style of an experienced programmer: registers and zero page for
  values, constants where the task fixes them (the copy sizes), no generic library routines.
